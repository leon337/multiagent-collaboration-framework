## 4. Tipos documentais

- **Normativo:** obrigações e autoridades.
- **Operacional:** procedimentos de execução.
- **Template:** estrutura reutilizável.
- **Histórico:** evidências, decisões e resultados passados.
- **Treinamento:** instruções e cenários de aprendizagem.
- **Experimento:** hipótese, execução, dados e retrospectiva.

## 5. Regra de leitura

Nenhum documento subordinado pode contrariar a Constituição. Em caso de conflito, registrar divergência e iniciar reconciliação antes de executar ou liberar.
