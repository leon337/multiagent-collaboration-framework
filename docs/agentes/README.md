## Invariantes

- total oficial de agentes: **49**;
- Leandro não é agente e não entra na contagem;
- participação de todos em uma missão continua proibida como padrão;
- seleção é dinâmica e por competência;
- cada agente nomeado deve possuir contrato individual nesta pasta;
- a matriz consolidada define função oficial, acionamento e fronteiras;
- contratos individuais não podem ampliar competências ou autoridade além das fontes canônicas;
- divergência entre esta pasta e a matriz oficial deve falhar na validação documental;
- agente convocado sem entrega real é não conformidade.
