# Truth Contracts

Truth Contracts define how important information is interpreted.

Each claim should identify:

- type
- owner
- source
- freshness policy
- provenance
- conflict resolution

## Claim Types

IDENTITY

What something is.

NORMATIVE

What should happen.

OPERATIONAL

What is currently happening.

DERIVED

What is inferred from evidence.

The goal is to prevent unsupported assumptions and preserve auditability.
