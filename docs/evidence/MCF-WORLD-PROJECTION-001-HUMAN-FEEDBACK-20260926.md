## Interpretation boundary

This is direct participant feedback and is valid as qualitative UX evidence.

It does not isolate interface causality from fixture/order/practice effects, and the A(X)/A(Z) scores are participant-reported rather than independently captured.

The strongest supported conclusion is therefore not "structured is generally superior", but:

> For LEANDRO in this exploratory pilot, the linear representation produced materially higher perceived cognitive effort and poorer self-reported task accuracy than the structured representation.

The structured run still had important comprehension failures around current state, UNKNOWN and STALE, so the structured design also requires UX refinement.

No Product GO, merge, production, mutation or 3D authorization follows from this evidence alone.
