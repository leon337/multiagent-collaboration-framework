# MCF — Nomenclatura aprovada para a próxima fase

Status: `APPROVED_BY_LEANDRO`

Nomenclatura canônica para documentação e planejamento:

**MCF — Fase 1: Reestruturação e Evolução Pós-v1**

Nome curto permitido em conversas: **MCF NextGen**.

Nome do estágio atual: **MCF NextGen — Discovery e Planejamento**.

Modelo didático:

- **Fase Zero — Construir para aprender**: ciclo atual/v1 usado para experimentar, errar, validar e descobrir limites reais do MCF.
- **Fase 1 — Reestruturar com o que aprendemos**: preservar acertos, corrigir falhas, simplificar excessos, remover o que não agrega valor e preencher lacunas.
- **Fase 2 — Provar e generalizar**: validar em projetos reais, comparar com baselines, testar outros modelos/executores e preparar uso por terceiros quando houver evidência suficiente.

Glossário didático preferencial:

- NextGen → Fase 1 — Reestruturação e Evolução
- NextGen Discovery → Estudo da Reestruturação
- Project Capsule → Pacote de Continuidade do Projeto
- Model Router → Roteador de Modelos de IA
- Human Dependency → Dependência Operacional Humana
- HUMAN_GATE → Decisão Reservada a LEANDRO, preservando `HUMAN_GATE` como identificador técnico
- Activity Feed → Linha do Tempo dos Agentes
- Interaction Center → Central de Perguntas e Decisões
- Project State → Estado Atual do Projeto
- Durable Memory → Memória Durável
- Live Operational State → Estado Operacional em Tempo Real

Esta decisão aprova somente a nomenclatura e o modelo didático de fases. Não aprova automaticamente hipóteses arquitetônicas ainda em estudo e não altera o boundary de `v1.0.0`.
