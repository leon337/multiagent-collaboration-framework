# N4 Accessibility Checklist

- [ ] essential meaning is not color-only
- [ ] contrast is readable
- [ ] type remains legible in portrait mobile
- [ ] captions have reserved area
- [ ] motion has reduced-motion variant where meaningful
- [ ] active recall does not flash rapidly
- [ ] Video Lab controls have labels
- [ ] Video Lab usable by keyboard
- [ ] focus indicator remains visible
- [ ] decorative motion can be removed without losing lesson meaning
