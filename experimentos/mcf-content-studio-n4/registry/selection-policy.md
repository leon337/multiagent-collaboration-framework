# Registry Selection Policy

Automatic selection is allowed only when:

1. status = APPROVED;
2. requested aspect is supported;
3. required assets are locally available;
4. dependency inventory is satisfied;
5. the component matches the learning intent.

Ranking signals for a future selector:

- learning intent match;
- aspect match;
- density match;
- reduced-motion compatibility;
- prior QA evidence.

A component with status DISCOVERED/REVIEWED/ADAPTED is never automatically selected.
