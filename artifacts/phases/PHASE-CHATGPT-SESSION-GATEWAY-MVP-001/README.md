# PHASE-CHATGPT-SESSION-GATEWAY-MVP-001

Pacote de rastreabilidade experimental (Classe B). Implementação: `tools/mcf-chatgpt-session-gateway/`.

- PLAN: escopo, autorização e riscos.
- REPORT: alterações e evidências observadas.
- VALIDATION / VALIDATION-FULL: provas automáticas.
- SMOKE: descoberta real read-only.
- CHECKPOINT: continuidade.
- DECISIONS: decisões, revisão pendente e limites.
- ARTIFACT-MANIFEST: checksums SHA-256.

Não equivale a aprovação de merge, autorização de deploy ou validação E2E cognitiva.

- PHASE-02-LIVE-QUALIFICATION: adendo de missão ChatGPT real via recuperação semântica; Gateway canônico ainda não qualificado.
