# MCF Content Studio N4 — Scale Decision

## Decision

`ESCALA_CONTROLADA_EM_NOVA_MISSAO`

The N4 foundation is approved as the baseline for the remaining nine lessons, but migration is not executed inside `MCF-CONTENT-STUDIO-N4-001`.

## Why controlled instead of mass migration

Evidence proves the framework and pilot, not every future lesson payload.

Each lesson must preserve:
- evidence-first factual source;
- one dominant focus per scene;
- short text;
- narration/visual synchronization;
- captions safe area;
- active recall where appropriate;
- 9:16 primary review;
- component matrix/lesson-specific visual QA;
- Review Lab artifact before master/publication.

## Recommended next mission

`MCF-CONTENT-STUDIO-N4-SCALE-001`

Scope:
- migrate nine remaining lessons using N4;
- reuse approved components/templates;
- add components only when a real pedagogical gap exists;
- render each lesson through Review Lab;
- run lesson-level QA;
- keep publication as a separate gate.

## Decision boundary

Approval to scale does not equal authorization to publish.
