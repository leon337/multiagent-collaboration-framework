## Honest limitations and remaining quality checks
- Audio signal and provider return tested with virtual input only; no real microphone, headset, echo cancellation or visible camera evidence.
- Browser playback queue bound simulated; no measured human-perceived jitter, underruns in production, p50/p95 robust samples or A/B physical benchmark.
- Real deliberate socket reconnect passed and received a resumable handle; equivalence of previous model context was not independently validated.
- GoAway signal tested by injection, not observed at the provider's natural connection timeout.
- HTTP 429/backoff, prolonged 10+min streaming and provider cost were not stress tested.
- Client VAD uses RMS threshold rather than a speech classifier; false positives require device-specific tuning.
- F0.8 remains pending and old previously exposed API key is intentionally unrotated by user decision. Do not publish server or gate release.
- No external agent Emily/LÉO is claimed to have executed; this PRF is a request for their real review, not a signed acceptance.
