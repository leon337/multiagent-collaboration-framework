# Authority Boundary

LEANDRO is the final human authority for this mission.

On 2026-09-23, LEANDRO authorized the mission to be created and executed continuously without asking permission to continue between normal steps.

Inside boundary:
- planning and architecture;
- reversible repository changes on the mission branch;
- tests and validation;
- documentation;
- issue/branch/PR preparation;
- implementation that does not require the powered-off local host.

Outside boundary:
- irreversible external publication or production deployment not already covered by repository governance;
- destructive actions against unrelated data or systems;
- fabrication of unavailable local state.
